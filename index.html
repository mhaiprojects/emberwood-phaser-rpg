    Settings

    Move with WASD or arrow keys. Click to walk. Eat shrimp or bread from Inventory. Bury bones, Trade, Fish, Bank from the panels. Auto-attack and auto-retaliate are on the Combat tab.

    Auto-pickup

    When on, walking near a loot pile picks it up. When off, click the pile to take it. New games start with this on.

    Shift-click drop

    When on, Shift+left-click drops an inventory item, like Old School RuneScape. Right-click Drop still works. New games start with this on.

    Hide bones

    When on, bone piles on the ground are hidden (OSRS ground-item overlay lite).

    Combat visuals

    When on, ranged/magic projectiles are shown in fights. New games start with this on.

    Show range rings

    When on, orange aggro circles and red attack-range rings appear while engaged, agroing, or fighting. New games start with this on.

    Mob spawn density

    Multiplies overworld pyramid spawn counts (Dragon=1, each lower tier +1). Applies on next zone enter. Deep Mine floor counts use the same multiplier.

    Controls

    WASD / arrows move, Ctrl run, Space talk, F1–F8 panels, click to walk/act.
