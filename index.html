Auto-attack

Toggle automatic engagement of nearby monsters, like classic RuneScape.

Auto-retaliate

When on, Attack is chosen for you in combat. Does not walk you into nearby foes.

Auto-pickup

When on, walking near a loot pile picks it up. When off, click the pile to take it. New games start with this on.

Shift-click drop

When on, Shift+left-click drops an inventory item, like Old School RuneScape. Right-click Drop still works. New games start with this on.

Run

Ctrl toggles run. Energy drains while running and restores while walking or idle.

Collision debug

F9 toggles arcade body outlines and colliding tiles. Off by default. Does not change WASD.
